# AI投研信号助手

个人项目,验证"LLM对新闻的情绪判断能否作为有效的短期价格预测信号"。

## 背景与问题

投资者做决策时依赖大量新闻/公告,人工阅读和判断效率低、主观性强。这个项目验证一个具体假设:用LLM自动提取新闻信息并给出情绪判断,这个判断是否比随机/无信号基线更能预测短期股价走势。

## 目标用户

关注美股(NASDAQ权重股)的个人投资者/分析师,希望用AI辅助信息处理而非替代决策。

## 核心假设

LLM对公司新闻的情绪分类(正面/负面/中性),在信号发出后1/3/5/10个交易日的价格表现上,显著优于基线(全部交易日的平均表现)。

## 产品方案

1. **数据层**:Finnhub拉取历史公司新闻,yfinance拉取历史价格数据
2. **AI层**:LLM(DeepSeek)对每条新闻做结构化情绪分类 + 简要理由,结构化输出(JSON)
3. **回测层**:计算信号发出后N个交易日的收益率,与基线对比,输出胜率、平均收益

## 覆盖范围(MVP)

- 标的:AAPL、MSFT、NVDA、AMZN、GOOGL、TSLA(NASDAQ-100权重股)
- 回测区间:近12个月
- 定位说明:先验证龙头股个股信号有效性,后续可扩展到指数成分股加权聚合的产品化路径

## 评估指标(效果验证)

- 正面/负面信号后N日胜率 vs 基线胜率
- 正面/负面信号后N日平均收益 vs 基线平均收益
- 分标的、分时间段的信号命中率分布

## 边界声明

本项目为研究性质的信号有效性验证工具,**不构成投资建议,不涉及实盘交易执行**。所有回测结果仅反映历史数据表现,不预示未来收益。

## 产品路线图(如果继续迭代)

- MVP(当前):验证少数龙头股信号有效性
- V2:扩展到指数成分股加权聚合信号
- V3:结合技术指标做多因子决策辅助工具
